## Problem

Twenty repositories' dependencies do not stay safe by hand. Vulnerabilities land daily; checking every repo manually means it never happens.

## Approach

- **Scan daily.** Every locked dependency across all 20 repos (2,213 on the first pass) is checked against the OSV/GHSA advisory database. First scan: 83 critical and 492 high findings, most in dormant tutorial repos — now visible and triaged instead of unknown.
- **Dashboard, not noise.** Findings and open Dependabot PRs are tracked in one private view, so attention goes to the active repos first.
- **Automate the safe parts.** A daily job opens config PRs adding `dependabot.yml` to repos missing one, and a guarded auto-merge workflow handles Dependabot security updates that pass CI.

## The guardrails are the point

The system never merges my code, never pushes to a default branch, and never changes a repo setting. Automation earns trust by staying inside its fence — human review remains exactly where it matters: the merge button.

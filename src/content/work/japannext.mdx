## What I build there

- **Market Access Control, from scratch.** Architected and built a client-facing application — application architecture, front-end, and middleware (React, Vite) — now used by ~30 external broker companies. The middleware layer transforms, filters, and restructures backend data for front-end consumption, with OpenAPI schemas and generated models/types keeping the API contract consistent.
- **Real-time monitoring for a matching engine.** Built a monitoring platform for a financial matching engine (React, TypeScript, AG Grid, OpenFin) integrating REST and WebSocket services — an internal tool used by the ~30-member operations team. Automated testing with Jest and Playwright at 90%+ coverage.
- **Operational control systems.** Contributed to business-critical systems that let authorized operators suspend trading sessions and cancel open orders.
- **Internal AI.** Supported self-hosted LLM deployments for internal AI initiatives.

Supporting work: contributed to a reusable Storybook component library, improving UI consistency and maintainability across teams.

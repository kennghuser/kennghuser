## Problem

Daily short-form publishing doesn't scale by hand — for any creator, not just language channels. Recording, editing, and posting one video a day, every day, is a second job.

## Approach

Build the system once, then let it run:

1. **Generate** — videos rendered programmatically from open data (for kanji: KanjiVG stroke-order data), 1080×1920, covers and captions produced in the same batch.
2. **Schedule** — a daily slot per platform, with a content queue planned weeks ahead.
3. **Publish** — YouTube Shorts and Instagram Reels from the same source file.
4. **Report** — a dashboard tracks views, engagement, and the Instagram → YouTube funnel, so the system is observable, not a black box.

Human judgement stays exactly where it matters: approving the content plan and the template. Everything repetitive is automated.

## Outcome

Customer #1 is [Kanji Daily](/work/kanji-daily): a 79-video series generated and published by this engine to two platforms, running hands-off on a daily schedule.
